# Taskly UI/UX Style Guide

| Token | Hex | Usage |
|---|---|---|
| Primary | `#635BFF` | Main CTA / active navigation |
| Primary Dark | `#5149E8` | Hover |
| Background | `#F7F8FC` | App background |
| White | `#FFFFFF` | Surfaces |
| Text | `#171A2B` | Main text |
| Muted | `#74798C` | Secondary text |
| Border | `#E8E9F0` | Borders / dividers |
| Success | `#22B573` | Completed |
| Warning | `#F5A623` | Medium priority |
| Danger | `#E55353` | Overdue / high priority |

## Typography
- Font: Inter
- Page heading: 29 px, 700–800
- Card heading: 16 px, 700
- Body: 13–14 px
- Small labels: 10–12 px

## Shape
- 9 px small radius
- 12 px medium radius
- 14 px large radius
- 42 px minimum button height

Shared CSS tokens: `frontend/styles/theme.css`.
