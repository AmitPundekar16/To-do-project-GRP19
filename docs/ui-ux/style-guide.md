# Taskly UI/UX Style Guide

| Token | Hex | Usage |
|---|---|---|
| Primary | `#725897` | Main CTA / active navigation |
| Primary Dark | `#5F497D` | Hover |
| Background | `#FAF5F2` | App background |
| White | `#FFFFFF` | Surfaces |
| Text | `#462D25` | Main text |
| Muted | `#806F69` | Secondary text |
| Border | `#EADEDB` | Borders / dividers |
| Success | `#5E9B7A` | Completed |
| Warning | `#D99A52` | Medium priority |
| Danger | `#C96D6D` | Errors / destructive actions |

## Typography
- Font: Inter
- Page heading: 30 px, 700–800
- Card heading: 19 px, 700
- Body: 13–14 px
- Small labels: 10–12 px

## Shape
- 10 px small radius
- 16 px medium radius
- 24 px large radius
- 30 px extra-large radius
- 42 px minimum button height

The font stack prefers Inter and falls back to system fonts. Shared CSS tokens are in `frontend/styles/theme.css`.
