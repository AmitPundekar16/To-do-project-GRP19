# Taskly UI/UX Design Specification

## Required screens
1. Login
2. Dashboard
3. Add Task
4. Task List

## Screen flow
Login → Dashboard → Add Task / Task List

## Layout
- Desktop artboards: 1440 × 900
- Sidebar: 240 px
- Responsive centered main content
- White cards with 1 px borders and rounded corners
- Mobile sidebar collapses to a menu

## Login
Taskly branding, email, password, remember me, forgot password, sign in, Google sign-in, create account.

## Dashboard
Sidebar, greeting, Add Task CTA, Total Tasks, Completed, In Progress, Overdue, Today's Tasks, Weekly Progress.

## Add Task
Task title, description, due date, priority, project, Cancel and Create Task.

## Task List
Search, All Tasks / Active / Completed, priority filter, task rows, due date, priority, status, edit and delete.
